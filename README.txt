FINPILOT
========
A local-first personal finance app prototype.

Included
--------
- Dashboard with net worth, cash, spending, bills, budgets, cash-flow chart, goals
- Accounts: add/edit/delete checking, savings, cash, credit card, investments, loans
- Transactions: add/edit/delete, search, month/category filters, CSV export/import
- Budgets: add/edit/delete categories with live spending progress
- Goals: add/edit/delete goals with target date and progress
- Bills: add/edit/delete recurring bills with due day and monthly totals
- Net worth: asset/liability breakdown and visual trend
- Settings: dark mode, currency selector, JSON backup/restore, reset sample data
- Local persistence using browser storage
- PWA manifest + service worker for hosted installations

Notes
-----
This version is intentionally bank-connection free. Automatic bank syncing would require a secure backend and a financial-data provider; those are not bundled into this free local build.
